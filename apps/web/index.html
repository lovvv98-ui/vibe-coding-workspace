PRIVATE BY DESIGN

계정은 각 서비스에,
전환은 작업공간에서.

로그인과 비밀번호를 수집하지 않습니다. 쿠키를 읽거나 외부 서버에 작업 데이터를 전송하지 않습니다. 브라우저에 이미 있는 탭을 찾아 앞으로 가져오는 역할만 합니다.

  • ✓ 기존 탭과 브라우저 세션 사용
  • ✓ 로그인 정보와 쿠키 저장 금지
  • ✓ 외부 사이트 iframe 미사용
  • ✓ 새 도메인은 추가 시 권한 확인

HELP & TROUBLESHOOTING

자주 묻는 질문

기본 동작과 흔한 문제를 빠르게 해결할 수 있도록 안내합니다.

기존 탭으로 이동하지 않아요.+

서비스 웹사이트가 아직 열려 있는지 확인하고, 확장 프로그램 사이드 패널을 새로 열어 보세요. 탭을 닫았다면 메뉴를 눌렀을 때 새 탭 열기 안내에서 직접 다시 열 수 있습니다.

서비스 탭이 중복으로 열려 있어요.+

같은 사이트 탭을 여러 개 사용 중이면 작업공간에서 선택 창을 표시합니다. 수업에서 이어갈 작업이 있는 탭을 선택하면 다음부터 그 탭을 우선 사용합니다.

로그인 상태가 풀렸어요.+

확장 프로그램은 로그인 여부를 확인하거나 세션을 복구하지 않습니다. 해당 서비스 탭에서 다시 로그인해 주세요. 로그인 세션은 각 서비스와 브라우저 정책에 따라 달라집니다.

브라우저를 다시 시작한 뒤 탭을 찾지 못해요.+

탭 ID가 바뀌면 저장된 주소를 기준으로 다시 검색합니다. 서비스 탭이 열려 있는지 확인하고, 사이드 패널에서 해당 서비스를 다시 선택해 보세요.

사이드 패널이 보이지 않거나 탭 이동 후 닫혀요.+

브라우저 도구 모음에서 확장 프로그램 아이콘을 눌러 패널을 다시 엽니다. Chrome 114 이상과 Edge는 사이드 패널 API를 지원합니다. Edge에서는 이전 탭으로 돌아왔을 때 사이드바가 자동으로 다시 표시되지 않는 알려진 동작이 있습니다.

서비스 URL을 바꾸거나 새 도구를 추가할 수 있나요?+

사이드 패널의 설정 버튼에서 이름과 URL, 순서, 사용 여부를 변경하고 새 서비스를 추가할 수 있습니다. 새 도메인에서는 브라우저가 요청하는 해당 사이트 권한을 허용해야 합니다.

탭을 전환하면 작업 화면이나 세션이 유지되나요?+

기존 탭을 닫거나 강제로 새로고침하지 않습니다. 다만 브라우저의 메모리 관리나 각 사이트 정책에 따라 화면이 다시 로드될 수 있습니다.
