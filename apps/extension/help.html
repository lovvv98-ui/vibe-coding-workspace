VIBE CODING WORKSPACE · 사용 안내

브라우저 한 창에서
도구를 바꿔가며 작업하세요.

사이드 패널 메뉴는 그대로 두고 현재 작업 탭 하나에서 서비스 화면을 전환합니다.

1

사이드 패널을 여세요

Chrome 또는 Edge 도구 모음에서 VIBE CODING WORKSPACE 아이콘을 누릅니다.

2

도구 메뉴에서 서비스를 고르세요

ChatGPT, Lovable, GitHub, Cursor, Vercel, InfinityFree 중 서비스를 선택하면 현재 탭의 주소가 바뀝니다. 서비스별 새 탭은 만들지 않습니다.

3

사이트에서 직접 로그인하세요

암호와 쿠키는 확장 프로그램에 저장하지 않습니다. 로그인 상태는 각 웹사이트에서 확인합니다.

4

필요한 작업을 저장한 뒤 전환하세요

이전에 방문한 서비스는 마지막 페이지 경로를 다시 엽니다. 서비스가 저장하지 않은 임시 입력은 화면 전환 시 사라질 수 있습니다.

서비스 URL의 검색어와 # 뒤 값은 저장하지 않습니다. 외부 서비스는 iframe에 넣지 않고 브라우저의 기본 작업 탭에서 열립니다.
