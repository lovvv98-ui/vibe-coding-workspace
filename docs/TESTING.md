# 수동 확인 안내

Chrome과 Edge에서 아래 항목을 각각 확인합니다. 확인하지 않은 항목은 완료로 표시하지 않습니다.

- [ ] 확장 프로그램을 개발자 모드에서 불러올 수 있음
- [ ] 사이드 패널이 열리고 7개 서비스가 순서대로 표시됨
- [ ] 교육 시작 전 탭 준비가 기존 탭을 재사용하고 빠진 서비스만 엶
- [ ] ChatGPT와 Codex URL 경로를 서로 다르게 찾음
- [ ] 메뉴를 여러 번 눌러도 동일 서비스 탭을 재사용함
- [ ] 중복 서비스 탭은 사용자가 선택할 수 있음
- [ ] 서비스 메뉴를 눌러도 페이지 새로고침이나 탭 닫기가 발생하지 않음
- [ ] 서비스 탭을 닫은 뒤 다음 선택에서 새 탭 만들기 안내가 나옴
- [ ] 브라우저를 다시 시작한 뒤 URL로 탭을 다시 찾음
- [ ] 옵션에서 서비스 추가, 편집, 삭제, 순서 변경, 비활성화, 기본값 복원을 할 수 있음
- [ ] 새 도메인을 추가할 때 해당 호스트 권한만 요청함
- [ ] 사이드 패널을 열어 둔 상태에서 탭 전환 동작을 확인함

로그인 상태 확인, 세션 유지, Codex Cloud 및 Cursor Cloud 계정 접근은 사용자가 해당 서비스에 로그인한 실제 브라우저에서 따로 점검합니다.
