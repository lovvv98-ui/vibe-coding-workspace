# 설치 안내

## Chrome

1. 확장 프로그램 폴더를 컴퓨터에 저장합니다. ZIP을 받았다면 먼저 압축을 풉니다.
2. Chrome 주소창에 `chrome://extensions/`를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json` 파일이 들어 있는 확장 프로그램 폴더를 선택합니다. GitHub 저장소를 내려받았다면 `apps/extension`, ZIP을 풀었다면 압축 해제된 폴더가 해당 위치입니다.
5. 퍼즐 모양 확장 프로그램 메뉴에서 VIBE CODING WORKSPACE를 고정하면 편리합니다.

## Microsoft Edge

1. 확장 프로그램 폴더를 컴퓨터에 저장하고 ZIP은 압축을 풉니다.
2. Edge 주소창에 `edge://extensions/`를 입력합니다.
3. 왼쪽 아래 또는 위쪽의 **개발자 모드**를 켭니다.
4. **압축 풀린 파일 로드**를 누르고 `manifest.json` 파일이 들어 있는 확장 프로그램 폴더를 선택합니다. GitHub 저장소를 내려받았다면 `apps/extension`, ZIP을 풀었다면 압축 해제된 폴더가 해당 위치입니다.
5. 도구 모음에 확장 프로그램을 고정합니다.

## 권한 안내

확장 프로그램은 현재 활성 탭의 주소를 확인해 작업 중인 서비스를 구분합니다. 기본 6개 사이트에서 현재 탭을 이동시키기 위한 주소 권한을 사용하며, 서비스의 콘텐츠, 암호, 쿠키에는 접근하지 않습니다.

## 사이드 패널 동작

Chrome 114 이상에서 Side Panel API를 지원합니다. Edge도 같은 `chrome.sidePanel` API를 지원합니다. Edge에서는 사이드바가 열린 상태로 탭을 이동할 수 있지만, 특정 탭으로 돌아왔을 때 사이드바가 자동으로 다시 표시되지 않는 알려진 동작이 있습니다. 이 경우 도구 모음의 확장 프로그램 아이콘을 눌러 다시 표시하세요.

## 업데이트

새 버전 폴더를 준비한 뒤 확장 프로그램 관리 화면에서 새 폴더를 다시 불러오거나 확장 프로그램을 새로고침합니다. 메뉴 전환은 현재 탭 하나를 재사용합니다. 서비스별 마지막 방문 경로는 브라우저에 저장하고, 로그인 세션은 각 사이트가 브라우저에 보관합니다.
