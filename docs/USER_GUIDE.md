# 사용 안내

1. Chrome 또는 Edge에 확장 프로그램을 설치합니다.
2. 도구 모음의 확장 프로그램 아이콘을 선택해 사이드 패널을 엽니다.
3. **교육 시작 전 탭 준비**를 눌러 7개 서비스 탭을 확인합니다. 없는 서비스만 새 백그라운드 탭으로 추가합니다.
4. 중복 탭 선택 창이 나오면 수업에서 사용할 기존 탭을 고릅니다.
5. 각 메뉴를 선택하고 서비스 웹사이트에서 직접 로그인합니다.
6. 수업 중에는 메뉴를 눌러 기존 작업 탭을 오갑니다.

| 서비스 | 교육 과정에서의 역할 |
| --- | --- |
| ChatGPT | 기획 및 프롬프트 작성 |
| Codex | GitHub 저장소 기반 클라우드 코딩 |
| Lovable | AI 기반 웹사이트 시안 및 구현 |
| GitHub | 코드 저장과 버전 관리 |
| Cursor | 브라우저 기반 AI 코딩 에이전트 |
| Vercel | 웹사이트 배포 |
| InfinityFree | 무료 호스팅 및 운영 실습 |

Codex와 Cursor 웹 Agent는 계정과 이용 권한이 필요할 수 있고, GitHub 저장소 연결 단계가 별도로 제공될 수 있습니다. PC용 Cursor 앱이나 Codex 앱은 제어하지 않습니다.

## 상태 표시

- **탭 열림**: 서비스 탭이 있습니다.
- **로그인 확인 필요**: 로그인 여부를 확장 프로그램이 알 수 없으므로 사이트 화면에서 확인해야 합니다.
- **로그인 여부 확인 불가**: 암호나 세션 상태를 읽지 않는 보안 설계입니다.
- **탭 없음**: 아직 연결된 탭이 없습니다.
- **중복 탭 · 선택 필요**: 같은 서비스 탭이 여럿 있어 수업에 사용할 탭을 골라야 합니다.

탭 ID가 브라우저 재시작 또는 탭 삭제로 바뀌거나 사라지면 서비스 주소를 기준으로 다시 찾습니다. 브라우저 메모리 관리나 외부 서비스 정책에 따라 페이지가 다시 로드될 수 있습니다.
