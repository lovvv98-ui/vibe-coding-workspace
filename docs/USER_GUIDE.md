# 사용 안내

이 작업공간은 브라우저 한 창의 사이드 패널 메뉴와 현재 작업 탭 하나를 함께 사용합니다. 서비스마다 새 탭을 만들지 않습니다.

1. Chrome 또는 Edge에 확장 프로그램을 설치하고 도구 모음에서 사이드 패널을 엽니다.
2. 도구 메뉴에서 ChatGPT 또는 원하는 서비스를 선택해 현재 탭에서 엽니다.
3. 서비스가 처음 열리면 해당 웹사이트에서 직접 로그인합니다.
4. ChatGPT, Lovable, GitHub, Cursor, Vercel, InfinityFree 메뉴를 누르면 현재 탭의 화면이 바뀝니다.
5. 이전에 방문한 서비스는 마지막 작업 경로로 다시 열립니다. ChatGPT 대화나 프로젝트가 서버에 저장되어 있다면 그 주소로 돌아갈 수 있습니다.

| 순서 | 서비스 | 교육 과정에서의 역할 |
|---:|---|---|
| 1 | ChatGPT | 기획 및 프롬프트 작성 |
| 2 | Lovable | AI 기반 웹사이트 시안 및 구현 |
| 3 | GitHub | 코드 저장과 버전 관리 |
| 4 | Cursor | 브라우저 기반 AI 코딩 에이전트 |
| 5 | Vercel | 웹사이트 배포 |
| 6 | InfinityFree | 무료 호스팅 및 운영 실습 |

## 화면 상태와 저장 정보

- **현재 화면**: 이 탭에서 해당 서비스가 열려 있습니다.
- **이어서 열기**: 이전 방문 주소가 저장되어 있어 다시 이동할 수 있습니다.
- **시작 전**: 아직 방문하지 않은 서비스입니다.
- **사용 중지**: 설정에서 숨긴 서비스입니다.

확장 프로그램은 로그인 여부를 확인하지 않고 암호나 쿠키를 저장하지 않습니다. 다시 이어 열 수 있도록 서비스별 마지막 경로를 이 브라우저의 저장소에 기록하며, 임시 토큰이 들어갈 수 있는 주소의 검색어와 `#` 뒤 내용은 저장하지 않습니다. 사이트가 서버에 저장하지 않은 임시 입력이나 브라우저 메모리 상태는 다른 서비스로 이동할 때 사라질 수 있으므로 먼저 저장해 주세요.

Cursor 웹 Agent는 계정과 이용 권한이 필요할 수 있습니다. PC용 Cursor 앱은 제어하지 않습니다.
